# SK Bento

Theme WordPress của https://sklight.vn (SK Ambient Light).

- Bản đang chạy trên hosting: thư mục `wp-content/themes/sk-bento`.
- Kho này là bản sao lưu và lịch sử thay đổi. Đẩy mã lên đây **không** tự cập nhật web; tệp vẫn phải đưa lên hosting.
- Khoá và mật khẩu nằm trong `wp-config.php` trên hosting, không lưu ở đây.
